# 室內地圖原型（獨立於主系統）

這個資料夾是實驗用的原型，**沒有任何程式會引用它**，也不影響 `src/`、`supabase/` 與建置。
平面圖資料（DXF）與產出的圖放在 `data/private/`，該目錄已被 `.gitignore` 排除，不會進版控。

## 目前的內容

`grid_rebuild.py`：把 CAD 平面圖（DXF）重建成「直角為主的乾淨格局」，並輸出一張靜態檢查圖。

```bash
python prototypes/indoor-map/grid_rebuild.py \
  "data/private/floorplans/航廈三樓-修改.dxf" \
  "data/private/indoor-map/航廈三樓_檢查圖.png" --title 航廈三樓
```

需要：Python 3、`ezdxf`、`shapely`、`matplotlib`。

## 做法

1. 只保留長線。柱、門框、傢俱與設備都是短線，不會成為牆。
2. 水平／垂直的牆對齊到精確的水平與垂直，雙線牆的兩面併成一條中心線；斷成幾段的牆接成一條。
3. 缺口在門寬以內（110 公分）就補起來，門不會把兩個房間連在一起。
4. 大弧線（半圓形格局、弧形立面）與 45 度牆保留原狀；小弧線（門的開啟弧）丟掉。
5. 把牆當成沒有厚度的線，加粗到足以封住門洞後取空白區域，再長回牆線。相鄰房間剛好在牆上相接。
6. 房間名稱取自圖上落在該房間內的文字。

## 已知限制

- 沒有牆線封閉的開放空間（例如大廳、走道與挑空相連的地方）會併成同一個區域。
- 單位預設為公分，面積門檻與門寬都以此為準。
- 目前只輸出靜態圖，沒有互動畫面與編輯功能；那是下一階段。
