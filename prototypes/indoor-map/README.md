# 室內地圖原型（獨立於主系統）

這個資料夾是實驗用的原型，**沒有任何程式會引用它**，也不影響 `src/`、`supabase/` 與建置。
平面圖資料（DXF）與產出的檔案放在 `data/private/`，該目錄已被 `.gitignore` 排除，不會進版控。

需要：Python 3、`ezdxf`、`shapely`、`matplotlib`（描圖工具本身只需要瀏覽器）。

## 目前的做法：描圖工具（`trace/`）

自動從 CAD 線稿取房間的效果不理想（牆線沒有封閉的地方會併成一大塊），所以改成**由人在底圖上描**，程式負責吸附、拉直與整理。有兩種描法，可以混用：

- **畫牆**：用「牆」工具把牆一條一條畫出來（線段就是牆）。牆圍成封閉區域，就會自動變成房間。
- **直接描房間**：用矩形、多邊形、半圓、圓直接描出房間外形。

```bash
python prototypes/indoor-map/trace/build_tracer.py \
  "data/private/floorplans/航廈三樓-修改.dxf" \
  "data/private/indoor-map/航廈三樓_描圖.html" --title 航廈三樓 \
  --locations data/private/indoor-map/locations.json
```

產出一個獨立的 HTML，雙擊即可開啟，不需要啟動系統。**每一層樓各產生一個檔案**（換 DXF 與 `--title` 即可）；每個檔案的資料各自存放，互不影響。

一個 DXF 若畫了好幾層或好幾個視圖（例如宿舍一、二樓同一個檔案、消防站是含圖框的圖紙），可以用 `--crop x0,y0,x1,y1`（圖面座標）只留下其中一個範圍，`--regions` 會列出檔案裡各自獨立的圖形範圍與座標，方便決定怎麼裁切：

```bash
python prototypes/indoor-map/trace/build_tracer.py "data/private/floorplans/宿舍一樓及二樓.dxf" /dev/null --regions
python prototypes/indoor-map/trace/build_tracer.py "data/private/floorplans/宿舍一樓及二樓.dxf"   "data/private/indoor-map/floors/宿舍一樓_描圖.html" --title 宿舍一樓 --crop 600,2000,9550,10600   --locations data/private/indoor-map/locations.json
```

### 套用其他樓層的形狀（對位）

各樓層外牆大致相同，但不同 DXF 的座標原點不一樣，直接匯入其他樓層的 JSON 會落在很遠的地方。建置時加上 `--align 其他樓層.dxf`（可重複），會用長牆線做 FFT 比對算出平移量（`trace/align_floors.py` 也可單獨執行）；比對不夠明確（分數 < 0.4 或和第二名差不到 10%）就不採用。

```bash
python prototypes/indoor-map/trace/build_tracer.py "data/private/floorplans/航廈二樓不含外部.dxf" "data/private/indoor-map/floors/航廈二樓_描圖.html" --title 航廈二樓 --locations data/private/indoor-map/locations.json --align "data/private/floorplans/航廈三樓-修改.dxf"
```

匯入來自其他底圖的 JSON 時，會自動平移對位，並詢問要保留還是清空存置地點代碼與名稱；位置有偏差，可用 Ctrl+A（或「全選」）選取全部，再用右側的移動面板微調，或用「對齊到底圖」（先點選取範圍上的頂點，再點底圖的端點或邊線）貼齊。

### 框選與群組

選取工具在空白處拖曳可框選（Shift 加選或減選）；選取多個物件後可整組拖曳、用方向鍵微調（步距自行輸入，Shift ×10）、輸入 x/y 距離移動，或對齊到底圖。右鍵、中鍵或空白鍵拖曳平移，F 縮放至全部。


`--locations` 是主系統現有存置地點的清單（代碼、名稱、財物筆數），由資料庫匯出成 JSON：
`[{"code": "*C001", "name": "業務組辦公室", "count": 92}, ...]`。沒有提供時，代碼與名稱只能手動輸入。清單含內部資料，放在 `data/private/`。

### 工具

| 工具 | 快捷鍵 | 用法 |
|---|---|---|
| 選取 | V | 點房間或牆選取；拖曳白點移動頂點；雙擊邊線加點；Delete 刪除頂點、房間或牆；拖曳房間可整個移動 |
| 牆 | W | 逐點點出牆；Enter、雙擊或點回起點完成；Backspace 退一點；Shift 鎖定水平／垂直 |
| 弧牆 | A | 弧形的牆：點起點、終點，再點弧線上的一點 |
| 矩形 | R | 按住拖曳，或依序點兩個對角 |
| 多邊形 | P | 逐點描出；Enter、雙擊或點回第一點完成；Backspace 退一點；Shift 鎖定水平／垂直 |
| 半圓 | C | 點直徑兩端，再點要凸出的一側 |
| 圓 | O | 點圓心，再點圓周 |

- 平移：按住空白鍵拖曳，或用滑鼠中鍵／右鍵拖曳；滾輪縮放。
- **吸附**：滑鼠靠近牆線端點、牆線、其他房間的頂點或邊線時會自動吸附（可關閉）。
- **自動整理**：頂點靠攏並吸到牆角、補上共邊頂點、近乎水平或垂直的邊拉成精確的水平垂直、移除多餘頂點。可以復原。
- 門不需要畫：牆畫成連續的就好，不需要留門洞。
- **由牆生成房間**：牆交叉或端點碰到另一道牆都會自動接起來；圍成封閉區域就產生房間。「即時生成房間」預設開啟，也可以按「由牆生成房間」手動產生。重新生成時，房間的名稱與類型會跟著所在位置保留；刪除由牆生成的房間後，同一個區域不會再被生成回來。
- 手動修改由牆生成的房間（拖曳頂點、移動）後，這個房間就變成手動房間，不會再被重新生成蓋掉。
- **存置地點**：選取房間後，在右側搜尋並選擇主系統的存置地點，代碼與名稱會一起帶入；也可以手動輸入。代碼不在主系統清單時會提醒；同一個存置地點可以由多個房間組成。
- 房間可設類型（房間／公共區域／挑空採光）。
- 左側清單與圖上標籤顯示的是存置地點，不是內部編號。
- 連著同一個端點的牆，拖曳其中一道的端點，其他牆的端點會一起移動，接合處不會被拉開。
- 資料自動存在這個瀏覽器（依檔案與瀏覽器各自儲存）；「匯出 JSON」取得檔案，「匯入」把先前匯出的 JSON 載入回來（換電腦、換瀏覽器、清除資料後還原，或繼續編修），匯入會取代目前的內容，可以復原。

### 匯出格式

```json
{
  "version": 4, "title": "航廈三樓", "source": "航廈三樓-修改.dxf", "unit": "cm",
  "walls": [
    { "id": "W001", "pts": [[3479, 4530], [3879, 4530]] }
  ],
  "rooms": [
    { "id": "T001", "locationCode": "*C001", "name": "業務組辦公室", "type": "room", "auto": true,
      "ring": [[3479, 4530], [3879, 4530], [3879, 4230], [3479, 4230]] }
  ]
}
```

座標是 DXF 圖面座標（x 向右、y 向上）。房間的 `locationCode` 與 `name` 是主系統的存置地點代碼與名稱；`id` 只是這個檔案內部的流水編號，**不是**存置地點代碼。`walls` 是牆的中心線，弧牆有 `curve: true`；`auto: true` 的房間是由牆生成的；`holes` 是這個房間裡面被其他房間完整佔用、面積要扣掉的部分（例如大廳裡四周自己圍牆的小房間）；半圓與圓房間會多帶 `curve` 欄位，之後可以還原成精確的圓弧。

## 等角視角檢視頁（`view/`）

用描好的房間做出一個獨立的檢視頁（玻璃卡片風格，參考設計圖）：

```bash
python prototypes/indoor-map/view/build_viewer.py   data/private/indoor-map/航廈三樓_等角檢視.html   --floor "3F|航廈三樓=data/private/indoor-map/航廈三樓.rooms.json"   --stats data/private/indoor-map/location-stats.json
```

- `--floor "標籤|名稱=檔案"` 每一層給一次，多層時會出現上一層、下一層與圓點分頁。
- `--stats` 是主系統各存置地點的財物統計（筆數、原值、淨值、財產大類筆數），由資料庫彙整；沒有提供時只顯示形狀。內含內部資料，放在 `data/private/`。
- 無陰影，牆是房間之間的細縫；已設定代碼的房間為白色，尚未對應為灰藍色，公共區域為深色，挑空／採光為虛線。
- 滑鼠：滾輪縮放、左鍵拖曳平移、**右鍵拖曳旋轉**（或按 Q／E）；點房間看存置地點、面積、財物筆數、原值淨值與財產大類。
- 底部的類別圖示（辦公空間、會議・接待、檔案・倉庫、廁所・茶水間、機房、公共區域）可點選，只標亮該類房間；「財物分布」依財物筆數上色；可依存置地點代碼或名稱搜尋。
- 房間類別依存置地點名稱的關鍵字判斷，尚未對應的空間不歸類。

### 魔術棒與拆分房間

- **魔術棒（M）**：游標移到房間內部會預覽並盡量判斷成「正幾何」，點一下建立，按住拖曳塗抹可把多處合併成一間。流程：把底圖的長牆線（加上你畫的牆與房間邊界）畫在 10 公分一格的網格上，線條加粗到能封住門口大小的缺口（預設「自動」，由 60、120、200 公分逐步放寬，也可固定一個值），從游標位置填滿，還原到真實牆線，再用開運算去掉漏進門口的部分。接著依序嘗試：矩形（含「大致是一個方盒、只有壁柱凹凸」的房間，邊貼齊底圖牆線）、圓、半圓、水平垂直的多邊形（邊拉齊到底圖自己的格線方向，小段階梯與凹凸被抹平）。圓與半圓會帶弧形資訊，之後仍可當作弧形房間。範圍沒封閉時會提示，可先用牆補缺口或調大缺口容忍。
- **牆切開手繪房間**：用矩形、多邊形、半圓、圓畫好的房間，被牆完整穿過時會自動拆成多間（最大的一塊保留原本的代碼與名稱，其他的是新房間）；牆只碰到邊或沒穿過則不拆。

### 修剪、延伸與對齊參考線

- **修剪／延伸（T）**：滑鼠移到牆上會預覽，紅色虛線是要刪掉的一段，點一下就刪到和其他牆（或手繪房間邊）的交點為止；牆的某一側沒有交點時刪到端點，被切成兩段的牆會變成兩道牆。按住 Shift 點牆的一端，則把那一端延伸到前方最近的牆、手繪房間邊或底圖長牆線（最遠 40 公尺）。可復原。
- **對齊參考線**：拖曳頂點、拖曳整個房間或群組、以及繪製牆與房間時，若與其他物件的頂點、邊界或中心線在同一條水平或垂直線上（約 6 個螢幕像素內），會出現洋紅色虛線並自動吸附；已經吸附到底圖角點或邊時不顯示。可用第二列的「參考線」開關。按住 Shift 鎖定方向時不啟用。

### 一棟樓一個頁面（多樓層）與存檔

- `trace/build_building.py 設定檔1.json 設定檔2.json … --title 標題 --output 輸出.html` 會把所有建築物（每個設定檔一棟）的所有樓層內嵌進同一個 HTML（全部約 14 MB），頁面上方先選建築物、再切換樓層（也可按 `[` `]`）。目前的組合：`build_building.py data/private/indoor-map/buildings/*.json --title 花蓮航空站平面圖製作工具 --key 航廈平面圖製作工具 --output data/private/indoor-map/花蓮航空站平面圖製作工具.html`。設定檔格式見該檔案的開頭說明：樓層由低到高列出、`reference` 指定對位的基準樓層、`crop` 裁切同一個 DXF 裡的不同樓層、設定檔放在 `data/private/indoor-map/buildings/`。
- 建置時會自動比對各樓層的外牆（FFT），算出各層相對基準樓層的平移量；比對不明確的樓層會顯示警告，該層不做自動對位（匯入其他樓層的形狀時會提示位置可能對不上）。匯入別層的 JSON 時，會依各層的對位量自動平移。
- 單層建置仍可用 `build_tracer.py`（`--align` 已移除，多層請用 `build_building.py`）。
- **存檔**：變動後約 0.7 秒自動寫進瀏覽器的 IndexedDB（每個樓層一份，換樓層不會互相覆蓋，重新整理會回到上次的樓層）。在 Chrome 或 Edge 可按上方「選擇專案資料夾」選一個資料夾，之後每次變動也會自動寫成 `<樓層名稱>.rooms.json`，這份才是正本；資料夾裡有比瀏覽器更新的檔案時，開啟或選擇資料夾會詢問是否載入。瀏覽器重開後需要點一次「資料夾需要重新授權」。其他瀏覽器只存在瀏覽器裡，請定期按「匯出 JSON」。

### 沒有牆的分區：分割線與固定房間

- **分割線**（S）：在一個沒有牆的開放空間裡畫一條線（可以多點、可以轉折，兩端要超出房間邊界或落在邊上），Enter 或雙擊完成。被線完整切開的房間會變成兩塊以上的手繪房間：最大的一塊保留原本的名稱與存置地點，其他塊是空的，再各自指派。之後不需要牆就會保持分開；房間裡原本被其他房間佔用的部分（鏤空）會跟著所在的那一塊。
- **固定房間**：已經用牆分出兩個房間、但實際上沒有牆時，選取房間按選取列的「固定房間」，它們就變成手繪房間，之後把牆刪掉也不會合併或消失（按復原可還原）。

- **合併房間**：選取兩個以上相連的房間（有共用邊、互相重疊，或一個完整在另一個裡面），選取列按「合併房間」合成一個手繪房間，名稱與存置地點取自有設定的那一間，其他間的代碼會變成「其他代碼」。分割線切過了不想切的房間時，用這個接回去。

- **扣掉重疊**：房間範圍畫得互相重疊時（例如服務臺壓在兩個大區塊上），選取壓在上面的房間，按選取列的「扣掉重疊」，它的範圍會從其他房間裡挖掉：完全在裡面就變成鏤空，只有一部分重疊就留下缺口，整條穿過就把對方切成幾塊。其他房間的邊界不會再穿過它，面積也不會重複計算。

### 底圖開關與刪除房間

- 第二列「底圖」（B）可整張關閉底圖；關閉時不會吸附到底圖，魔術棒與延伸也不再參考底圖，只看你描的牆與房間。「淡化底圖」「短線」「原圖文字」仍可分別控制。
- 刪除由牆生成的房間時，若它原本是某個大空間裡的鏤空，大空間會把這塊空間收回（鏤空消失），不會失效或殘留破洞。
- 刪除由牆生成的房間時，預設會讓「共用最多牆」的相鄰房間接手它的空間：兩者之間的牆段一起拿掉，房間內部多出的牆也拿掉，其他房間還需要的牆都保留，相鄰的大房間因此不會失效。房間面板另有「只刪除房間，保留牆」，只是不再把那塊當成房間。房間只和外部相鄰（沒有鄰居可以接手）時也是這種做法。
- 同一層樓如果由兩份圖組成（例如航廈地下一樓＝`航廈地下一樓.dxf`＋`航廈淺漥區.dxf`，淺漥區是同一層北側的延伸，座標相同），在設定檔的樓層加上 `"extra": [{"dxf": "…"}]`，底圖就會合併。`seedDxf` 指定預載資料原本描在哪一份底圖上，建置時會自動算出兩份底圖的差距並平移（航廈三樓：`航廈三樓.dxf` 相對 `航廈三樓-修改.dxf` 差 x 7、y −3 公分）。
- 頁面只收進 LINE、ARC、CIRCLE、LWPOLYLINE、POLYLINE、ELLIPSE 與單行文字 TEXT；方塊（INSERT）、尺寸標註、填充、多行文字（MTEXT）、3DFACE 都不會顯示。座標四捨五入到 0.1 公分，沒有另外壓縮（14.6 MB；若用 gzip 約 3 MB）。

### 資料不寫死在頁面裡

- 頁面只內嵌底圖。你描的房間、存置地點清單都**不會**寫進頁面，一律從瀏覽器的儲存空間（IndexedDB）與專案資料夾讀取，所以更新底圖或程式不需要帶資料，也不會被舊資料蓋掉。
- 新瀏覽器第一次使用：選專案資料夾（資料夾裡有 `<樓層名稱>.rooms.json` 就會載入），或用「匯入 JSON」逐層匯入；存置地點清單用右側「存置地點清單」分頁的「匯入清單」匯入一次（`locations.json`，內容 `[{code, name, count}]`），之後記在瀏覽器裡，也會備份成專案資料夾裡的 `存置地點清單.json`。

### 空間用途與存置地點清單

- 房間面板的「空間用途」可以自行標註不屬於存置地點的空間（走廊、樓梯間、機房……），下方有常用與已用過的用途可一鍵套用；沒有代碼與名稱時，地圖與列表會顯示用途（斜體），匯出的 JSON 也帶 `usage`（版本 5）。
- 右側「存置地點清單」分頁：列出每個存置地點對應到哪些樓層的哪些房間（點房間標籤會跳過去）；可篩選「未對應」「已對應」「清單外代碼」「無存置地點的房間」；選取房間後，清單裡每筆都有「指派給選取的房間」；「匯出對照表」輸出 CSV。

### 缺口檢查

第二列「缺口檢查」：找出牆的端點「沒接到任何牆、但離另一道牆很近」的地方（預設 50 公分內，可改），建議往前延伸或接到最近的牆。補上之後會多一個封閉房間的標紅色（高信心），其餘標灰色（可能是刻意留的隔牆端點，預設不動）。每一處可單獨「補上」或「看」，也可以「全部補上紅色的」，一次動作可復原。只處理直線牆；超過距離的開口（例如門）不會自動補。

### 批次找房間

第二列「批次找房間」：整層找出一個個房間候選，疊在地圖上讓你勾選接受（不預填存置地點）。做法：把底圖（長牆線）、你畫的牆與房間邊畫成網格，空地往內縮「門口寬度上限」的一半，房間和走廊之間不寬於上限的門口就會斷開，各自留下一個核心；其餘空地歸到最近的核心；再對每個區域用魔術棒的形狀判斷。形狀是矩形（含「大致是方盒」）、圓、半圓或「矩形加半圓」（長形房間一端是半圓），而且吻合度 ≥ 85% 的才算規則形狀、預設勾選；其他標成「請人工檢視」、預設不勾。已經有房間的位置不會再提供。接受後是手繪房間（一次動作可復原），接著用「存置地點清單」分頁指派。

限制：門口比上限寬的房間會和走廊連成一塊；比兩倍上限窄的小房間（例如櫃子）找不到；你把幾個小隔間合併成一間大房時，候選會比你描的小。以航廈三樓對照（46 間人工描的房）：預設 150 公分時 45 間有候選落在裡面，約三分之一面積相近。

### 右側面板的版面

- 所有放名稱的地方都是單行，過長用省略號，滑過去顯示全文，不會把名稱從中間折成兩行。
- **存置地點清單**：最上面是「已對應 N / 總數」加進度條；「目前選取的房間」那條顯示它的編號、面積與目前的指派，旁邊「下一間未指派」；選了房間後，點清單裡任一列（滑過去會顯示「指派給 T008」）就指派，並跳出可復原的小通知；有對應的列下面才顯示房間標籤（點了會跳過去）；匯入清單、匯出對照表收在右上「⋯」。
- **房間**：列表標題是存置地點（沒設定時是編號與面積），副標是編號與面積；未設定的整列淡色加橘線，排在最後（面積大的在前）；資訊面板分成存置地點、空間用途、房間資訊三張卡片，最上面有「‹ ›」與「下一間未指派」，刪除按鈕固定在最下方。

### 房間編號與永久識別碼

- **編號（T097）**只是這一層內部的流水號，只增不減，刪掉的編號不會重用。
- **匯入別層的檔案**時，裡面的房間與牆視為複製品：編號改成這一層接下來的號碼，識別碼也換新；同一層自己的備份還原則保留原編號與識別碼。
- **永久識別碼（uid）**：每個房間建立時就有一個看不見的隨機識別碼，改編號、改名稱、牆重新生成、複製到別層都不會讓原房間的識別碼改變（由牆生成的房間重新生成時沿用）。JSON 的每個房間帶 `uid`（版本 6）；舊資料在下次開啟那一層時自動補上並存檔。房間資訊卡片的「識別碼」只顯示前 8 碼，滑過去看完整的。日後接資料庫時，用它當房間的主鍵。

### 改標題時不要讓已存的資料消失

瀏覽器存資料的名稱是 `--key`，和頁面標題 `--title` 分開。只想改標題時，請保持同一個 `--key`（目前是 `航廈平面圖製作工具`）；key 一改，頁面就找不到之前存在瀏覽器裡的樓層與存置地點清單（它們還在，只是換了名字找不到）。
